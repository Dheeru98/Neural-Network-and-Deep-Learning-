# Neural-Network-and-Deep-Learning-
This repository contains Neural Network and Deep Learning - It includes neural network concepts, TensorFlow tensor manipulation, loss function comparison, MNIST classification using Adam and SGD optimizers, and TensorBoard training analysis.
## Topics Covered

- Artificial Intelligence, Machine Learning, and Deep Learning
- Neural Network Layers
- Weights and Biases
- Activation Functions
- Perceptrons
- AND, OR, and XOR Problems
- Sigmoid, Tanh, and ReLU
- Vanishing Gradient Problem
- Neural Network Training Process
- Tensor Manipulation
- Loss Functions
- MNIST Classification
- Adam and SGD Optimizers
- TensorBoard
- ## Programming Tasks

### 1. Tensor Manipulation
Created and reshaped tensors using TensorFlow and demonstrated broadcasting.

### 2. Loss Functions
Compared Mean Squared Error (MSE) and Categorical Cross-Entropy.

### 3. Adam vs. SGD
Trained MNIST models using Adam and SGD and compared their accuracy.

### 4. TensorBoard
Trained an MNIST neural network for 5 epochs and analyzed training and validation accuracy and loss using TensorBoard.
